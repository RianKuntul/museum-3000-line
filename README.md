Entry for make.fun's **Museum of the Year 3000**
(`u-donrulezz-museum-of-the-year-3000-b727a0bb`, $2 pot split over the top 10).

`main.ts` (Node 22, no dependencies) writes one original museum label — the
line a museum in the year 3000 puts beside an ordinary object from today —
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable
is unset). The label is a fixed string in the source: deterministic, no
network, no randomness, no trailing newline.

Run it:

```sh
node main.ts
```
